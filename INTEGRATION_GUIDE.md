# Integration Guide: Adding MudHistoryControl to the Project

## Step 1: Add Swift Files to Xcode Project

You need to manually add the Swift files to your Xcode project:

### Instructions:

1. **Open Xcode**
   - Open `Mudrammer.xcworkspace` (not the .xcodeproj)

2. **Locate the files to add:**
   - `src/Mudrammer/Views/Buttons/MudHistoryControl.swift`
   - `src/Mudrammer/Views/Buttons/MudHistoryControlTests.swift` (optional, for tests)

3. **Add MudHistoryControl.swift to the project:**
   - In Xcode, find the "Views/Buttons" group in the Project Navigator (left sidebar)
   - Right-click on the "Buttons" folder
   - Select "Add Files to 'Mudrammer'..."
   - Navigate to `src/Mudrammer/Views/Buttons/`
   - Select `MudHistoryControl.swift`
   - **Important:** Make sure these options are checked:
     - ✅ Copy items if needed (leave UNCHECKED - file is already in the right place)
     - ✅ Create groups
     - ✅ Add to targets: Select "MUDRammer" target (both Dev and Release)
   - Click "Add"

4. **Add MudHistoryControlTests.swift (optional):**
   - Repeat the same process for the test file
   - When adding, select the test target (if you have one)

5. **Verify the bridging header:**
   - I've already updated `MUDRammer-Bridging-Header.h` for you
   - It now imports `SPLImagesCatalog.h` which is needed by the Swift code

6. **Build the project to verify:**
   - Press `Cmd+B` to build
   - Fix any build errors that appear

## Step 2: Update SSMUDToolbar to Use MudHistoryControl

Now we need to update the toolbar to use the new Swift implementation. You have two options:

### Option A: Keep Objective-C (Easier, Recommended)

Keep `SSMUDToolbar.m` in Objective-C but use the new Swift `MudHistoryControl`:

1. **Import the generated Swift header** in `SSMUDToolbar.m`:
   ```objc
   // At the top of SSMUDToolbar.m, add:
   #import "Mudrammer-Swift.h"  // This is auto-generated by Xcode
   ```

2. **Change the property type** in `SSMUDToolbar.m` (or .h if declared there):
   ```objc
   // Change from:
   @property (nonatomic, strong) SSMudHistoryControl *historyControl;

   // To:
   @property (nonatomic, strong) MudHistoryControl *historyControl;
   ```

3. **Update the initialization** (wherever historyControl is created):
   ```objc
   // Change from:
   self.historyControl = [[SSMudHistoryControl alloc] init];

   // To:
   self.historyControl = [[MudHistoryControl alloc] init];
   ```

4. **Update the arrow key handler** to pass current input:
   ```objc
   - (void)growingTextViewPressedKeyCommand:(NSString *)direction {
       NSString *currentText = [self.textView.text copy];

       if ([direction isEqualToString:UIKeyInputUpArrow]) {
           if ([self.historyControl isAtStart]) {
               return;
           }

           // NEW: Pass current input for smart filtering
           [self.historyControl moveHistory:HistoryNavigationDirectionBackwards
                               currentInput:currentText];

       } else if (![self.historyControl isAtEnd]) {
           [self.historyControl moveHistory:HistoryNavigationDirectionForwards
                               currentInput:nil];
       }
   }
   ```

5. **Update the delegate method** (should work as-is, but verify):
   ```objc
   - (void)mudHistoryControl:(MudHistoryControl *)control
        willChangeToCommand:(NSString *)command {
       if ([self.textView isEditable]) {
           [self.textView setText:command];
       }
   }
   ```

### Option B: Convert SSMUDToolbar to Swift (More Work)

If you want to go full Swift, you could convert the entire `SSMUDToolbar` class to Swift. This would be a larger refactoring task.

## Step 5: Test the New Behavior

1. **Build and run** the app on a simulator or device

2. **Test basic history:**
   - Send commands: "north", "south", "east"

3. **Test smart prefix filtering:**

## Troubleshooting

### Build Error: "Use of undeclared identifier 'MudHistoryControl'"

**Solution:** Make sure you added the Swift file to your target:
1. Select `MudHistoryControl.swift` in the Project Navigator
2. Open the File Inspector (right sidebar)
3. Under "Target Membership", ensure "MUDRammer" is checked

### Build Error: "Use of undeclared identifier 'SPLImagesCatalog'"

**Solution:** Check the bridging header:
1. Verify `MUDRammer-Bridging-Header.h` contains `#import "SPLImagesCatalog.h"`
2. In Build Settings, verify "Objective-C Bridging Header" points to the correct file

### Runtime Error: "Selector not found"

**Solution:** Make sure the Swift class is marked with `@objc`:
- The class and methods should have `@objc public` annotations (already done in the implementation)

### History Doesn't Work

**Solution:** Verify the delegate is set:
```objc
self.historyControl.delegate = self;
```

## Quick Reference: Code Changes

### File: SSMUDToolbar.m

**Before:**
```objc
#import "SSMudHistoryControl.h"

@property (nonatomic, strong) SSMudHistoryControl *historyControl;

- (void)growingTextViewPressedKeyCommand:(NSString *)direction {
    NSString *currentText = [self.textView.text copy];

    if ([direction isEqualToString:UIKeyInputUpArrow]) {
        if ([self.historyControl isAtStart]) {
            return;
        }

        if ([self.historyControl isAtEnd] && [currentText length] > 0) {
            [self.historyControl addCommand:currentText];
            [self.textView setText:@""];
            [self.historyControl moveHistory:HistoryDirectionBackwards];
        }

        [self.historyControl moveHistory:HistoryDirectionBackwards];
    } else if (![self.historyControl isAtEnd]) {
        [self.historyControl moveHistory:HistoryDirectionForwards];
    }
}
```

**After:**
```objc
#import "Mudrammer-Swift.h"

@property (nonatomic, strong) MudHistoryControl *historyControl;

- (void)growingTextViewPressedKeyCommand:(NSString *)direction {
    NSString *currentText = [self.textView.text copy];

    if ([direction isEqualToString:UIKeyInputUpArrow]) {
        if ([self.historyControl isAtStart]) {
            return;
        }

        // Smart prefix filtering - pass current input
        [self.historyControl moveHistory:HistoryNavigationDirectionBackwards
                            currentInput:currentText];

    } else if (![self.historyControl isAtEnd]) {
        [self.historyControl moveHistory:HistoryNavigationDirectionForwards
                            currentInput:nil];
    }
}
```

### Key Differences:

1. **Import changed** from `SSMudHistoryControl.h` to `Mudrammer-Swift.h`
2. **Type changed** from `SSMudHistoryControl` to `MudHistoryControl`
3. **Method signature changed** to include `currentInput:` parameter
4. **Removed the "stashing" logic** - now handled automatically by the smart filtering
5. **Simplified navigation** - no need to move twice or manually add current text

## Expected Behavior Change

### Old Behavior:
- Type "n" → Press Up → Shows "east" (last command, ignoring input)

### New Behavior:
- Type "n" → Press Up → Shows "north" (last command starting with "n")

This makes command history much more intuitive and efficient!
